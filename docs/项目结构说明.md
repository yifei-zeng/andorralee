# Andorralee 蜜罐诱捕系统 · 项目结构说明（实装版）

本文根据当前代码库实际实现梳理目录与功能，便于快速上手与排障。

## 项目概述
Andorralee 是基于 Go 的蜜罐诱捕平台，集成容器化蜜罐部署、攻击会话捕获与统计、恶意文件检测、端口与日志管理等能力。

后端基于 Gin，使用关系型数据库并通过 GORM 自动迁移核心表结构。默认对外监听 9090 端口，静态页位于 `static/`（根路径回退到 `index.html`）。

## 目录结构（精简）

```
andorralee/
├── cmd/
│   ├── main.go                 # 程序主入口（加载 Docker、数据库，执行 AutoMigrate，启动 Gin）
│   └── dbtest/main.go          # 数据库连接性测试小工具（读取环境变量）
├── internal/
│   ├── config/
│   │   ├── config.go           # 加载环境、初始化 Docker/数据库、AutoMigrate 表
│   │   └── honeypot_config.go  # 预置蜜罐类型与默认镜像/端口
│   ├── handlers/               # 各域 HTTP 处理器
│   ├── repositories/           # 数据模型与数据库访问实现
│   └── services/               # 业务编排（数据库、Docker、统计聚合等）
├── routers/router.go           # 全量路由，API 前缀 /api/v1，含健康检查与静态资源
├── deployment/
│   ├── init_db.sql             # 初始化数据库与核心扫描表（含 CREATE DATABASE）
│   ├── create_tables.sql       # 初版表（蜜罐/诱饵/规则/日志/Docker 相关）
│   └── update_database_schema.sql  # 统一字段类型、索引与新增视图
├── pkg/                        # 公共包（CORS 中间件、日志等）
├── static/                     # 前端静态资源（根路由回退）
├── frontend/                   # Demo 页面（端口管理、容器调试）
├── build/                      # 构建产物目录
├── docker-compose*.yml         # 部署编排
├── go.mod                      # 模块与 Go 版本（go 1.23.4）
└── docs/                       # 文档
```

## 已实现功能清单（按域归类）

- 健康检测与静态资源
    - GET `/health` 与 `/api/v1/health|ready|live`；静态 `/` 回退到 `static/index.html`

- Docker 镜像与容器管理（handlers.docker_* 与 services/docker_services.go）
    - 拉取/启动/停止镜像与容器；列出/查询/删除镜像；容器信息/日志
    - 镜像操作日志持久化与查询（image-logs）

- 容器实例与临时实例
    - 容器实例 CRUD、部署镜像、启停重启、状态同步、调试信息
    - 临时容器实例（内存容器）创建/启停/端口扫描/状态同步

- 蜜罐管理与日志
    - 蜜罐实例查询、部署、停止、实例日志查询
    - 蜜罐模板查询/按模板部署/协议列表

- 诱饵（蜜签）与蜜签事件
    - 诱饵 CRUD、部署状态更新
    - 蜜签 CRUD、触发记录、统计；默认蜜签初始化（启动时）

- 安全规则与规则日志
    - 规则 CRUD、启用/禁用；规则日志查询

- 端口能力
    - 端口扫描（对容器）与端口管理（分配/释放/可用性/统计）

- 攻击捕获与会话
    - 攻击事件上报、按 IP/统计维度查询
    - 会话查询、事件明细、关闭会话、活跃度/时间范围统计、认证与命令记录

- 日志分析
    - 容器运行时日志解析与存储，按容器/时间/事件类型/IP/统计聚合，导出

- 恶意软件检测
    - 文件/URL 扫描、上传、按 ID 启动扫描、结果与统计，特征签名增查

- 威胁情报
    - 情报存取、威胁评估与统计

- 第三方蜜罐日志
    - Heralding 认证日志拉取/查询/统计
    - Cowrie 日志拉取/查询/统计（含命令/用户名/密码/指纹 TopN）

以上功能均已在 `routers/router.go` 注册对应 REST API（前缀 `/api/v1`）。

## 数据库支持与初始化

- 数据库类型：
    - 关系型数据库（推荐 8.0+ 兼容版本）

    - 在 `cmd/main.go` 启动时调用 `config.InitDatabase()` 与 `config.InitTables()`。
    - GORM AutoMigrate 会创建/更新以下核心表（节选）：
        - 蜜罐/实例/日志：`honeypot_template`、`honeypot_instance`、`honeypot_log`
        - 诱饵与规则：`bait`、`security_rule`、`rule_log`
        - Docker 相关：`docker_image`、`docker_image_log`、`docker_container`、`container_log_segment`
        - 日志与统计：`heralding_auth_log`、`cowrie_log`
        - 威胁检测：`malware_signature`、`scan_result`、`detection_result`
        - 攻击域：`attack_session`、`attack_event`
        - 蜜签事件：`honeytoken_event`

- 初始化脚本（可选）：
    - `deployment/init_db.sql`：创建数据库 `andorralee` 并初始化扫描相关表（含索引/唯一约束）。
    - `deployment/create_tables.sql`：基础表（蜜罐/诱饵/规则/日志/Docker）。
    - `deployment/update_database_schema.sql`：字段对齐、索引与统计视图（如 `v_cowrie_*`、`v_heralding_*`）。

注意：GORM 不会创建数据库本身，首次安装数据库后请先确保存在 `andorralee`，或执行 `init_db.sql` 来创建数据库再启动服务。

## 运行要点

- 环境变量（默认值见 `internal/config/config.go`）：
    - `MYSQL_HOST=localhost`、`MYSQL_PORT=3306`、`MYSQL_USER=root`、`MYSQL_PASSWORD=123456`、`MYSQL_DATABASE=andorralee`
- 端口：服务监听 `:9090`；API 前缀 `/api/v1`；静态资源 `/static/*` 与根路由回退。
- Swagger：当前已禁用（保留注释位置）。

## 技术栈

- Go 1.23.4、Gin、GORM（关系型驱动）、Docker SDK
- 前端静态页：`static/` 与 `frontend/` 下示例页面

## 质量与安全

- 中间件：CORS（`pkg/middleware/cros.go`）
- 日志：`pkg/utils/logger.go`
- 基本健康检查与分层架构（handlers/repositories/services）

## 变更与维护

- 主要路由与能力集中在 `routers/router.go`，如新增域能力请先在此注册。
- 数据结构统一在 `internal/repositories/models.go`，新增表需同步到 AutoMigrate 清单。
- Docker 与数据库依赖失败时服务不会崩溃，但相关 API 将返回友好错误（在 `cmd/main.go` 中可见容错加载逻辑）。
