# Andorralee 蜜罐诱捕系统项目结构

## 项目概述
Andorralee v2.0 是基于 Go 语言开发的企业级蜜罐诱捕系统，支持多协议蜜罐部署、攻击行为捕获、病毒检测和可视化分析。

## 主要模块说明

### 1. 核心模块 (internal/)
- **config/**: 系统配置管理，包括基础配置和蜜罐特定配置
- **handlers/**: HTTP请求处理器，实现RESTful API
- **repositories/**: 数据访问层，支持MySQL和达梦数据库
- **services/**: 业务逻辑层，核心功能实现

### 2. 公共模块 (pkg/)
- **middleware/**: HTTP中间件，如CORS处理
- **utils/**: 通用工具函数，日志和响应处理

### 3. 路由模块 (routers/)
- **router.go**: 统一的路由配置和API端点定义

### 4. 构建和部署
- **build/**: 编译输出目录
- **deployment/**: 生产环境部署脚本和配置
- **tools/**: 开发和运维工具

### 5. 前端模块 (frontend/)
- 当前包含基础HTML界面
- 计划开发React.js前端应用

### 6. 测试模块 (tests/)
- **unit/**: 单元测试
- **integration/**: 集成测试  
- **e2e/**: 端到端测试

## 技术栈

### 后端技术
- **语言**: Go 1.21+
- **框架**: Gin (HTTP Web框架)
- **数据库**: MySQL 8.0 / 达梦数据库
- **容器化**: Docker & Docker Compose
- **依赖管理**: Go Modules

### 前端技术 (计划)
- **框架**: React.js + TypeScript
- **UI库**: Ant Design
- **图表库**: ECharts
- **状态管理**: Redux Toolkit
- **构建工具**: Create React App

### 基础设施
- **容器编排**: Docker Compose
- **反向代理**: Nginx (可选)
- **监控**: Prometheus + Grafana (计划)
- **日志**: 结构化日志 + ELK Stack (计划)

## 开发规范

### 1. 代码组织
- 遵循Go项目标准布局
- 使用内部包封装业务逻辑
- 公共包提供可复用组件

### 2. 命名规范
- 文件名使用snake_case
- 包名使用小写字母
- 常量使用大写字母

### 3. 文档规范
- 重要功能必须有文档说明
- API接口提供OpenAPI规范
- 变更记录维护在RELEASE_NOTES.md

### 4. 测试规范
- 单元测试覆盖率要求 > 80%
- 关键业务逻辑必须有集成测试
- 发布前进行端到端测试

## 部署架构
