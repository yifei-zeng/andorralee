# Andorralee 蜜罐诱捕系统项目结构

## 项目概述
Andorralee v2.0 是基于 Go 语言开发的企业级蜜罐诱捕系统，支持多协议蜜罐部署、攻击行为捕获、病毒检测、威胁情报、蜜签 (Honeytoken) 以及多数据库（MySQL / 达梦 DM）双模运行。新增：
1. DB_MODE 运行模式 (mysql|dameng) 动态选择数据库连接。
2. 全量 MySQL / 达梦 建表脚本与自动迁移结合。
3. Schema 异步自检（启动后校验关键表/列完整性）。
4. 分页与日期统一构造工具，隐藏不同方言差异。
5. 达梦布尔/JSON/TEXT 兼容（数值 0/1 + CLOB/VARCHAR 存储）。
6. is_active 等字段在达梦缺失/别名时增加回退策略，确保查询不报错。

## 主要模块说明

### 1. 核心模块 (internal/)
- **config/**: 系统配置管理，包括基础配置和蜜罐特定配置
- **handlers/**: HTTP请求处理器，实现RESTful API
- **repositories/**: 数据访问层，支持MySQL和达梦数据库
- **services/**: 业务逻辑层，核心功能实现

### 2. 公共模块 (pkg/)
- **middleware/**: HTTP中间件，如CORS处理
- **utils/**: 通用工具函数，日志和响应处理

### 3. 路由模块 (routers/)
- **router.go**: 统一的路由配置和API端点定义

### 4. 构建和部署
- **build/**: 编译输出目录
- **deployment/**: 生产环境部署脚本和配置
- **tools/**: 开发和运维工具

### 5. 前端模块 (frontend/)
- 当前包含基础HTML界面
- 计划开发React.js前端应用

### 6. 测试模块 (tests/)
- **unit/**: 单元测试
- **integration/**: 集成测试  
- **e2e/**: 端到端测试

## DB_MODE 多数据库运行机制
| 环境变量 | 说明 | 示例 |
|----------|------|------|
| DB_MODE | 选择 mysql 或 dameng | dameng |
| MYSQL_HOST / PORT | MySQL 主机端口 (映射 13306) | 127.0.0.1 / 13306 |
| DAMENG_HOST / PORT | 达梦主机端口 | 127.0.0.1 / 5236 |
| MYSQL_DB / MYSQL_USER / MYSQL_PASSWORD | MySQL 连接信息 | andorra / root / xxx |
| DAMENG_DATABASE / DAMENG_USER / DAMENG_PASSWORD | 达梦连接信息 | DOCKER_OPS / SYSDBA / xxx |

核心函数：config.GetActiveDB(), config.GetDBByMode(mode)；若当前模式连接失败，可回退另一可用库（策略可配置）。

## 达梦数据库核心表结构 (节选)
| 表 | 关键字段 | 说明 |
|----|----------|------|
| malware_signature | id,name,pattern,type,severity,is_active | 恶意软件特征库 |
| scan_result | id,file_hash,file_name,scan_time,is_infected,threat_level | 扫描结果汇总 |
| detection_result | id,scan_result_id,signature_id,match_type,severity | 具体命中记录 |
| attack_session | id,session_id,source_ip,start_time,status,threat_level | 攻击会话 |
| attack_event | id,session_id,event_type,event_time,command,payload | 攻击事件 |
| threat_intelligence | id,indicator_type,indicator_value,severity,is_active | 威胁情报指标 |
| honeytoken_event | id,token_id,token_type,trigger_time,source_ip | 蜜签触发 |
| headling_auth_log | id,auth_id,session_id,source_ip,username,password | 认证尝试日志 |
| cowrie_log | id,auth_id,session_id,source_ip,command,protocol | Cowrie 日志 |
| docker_container | id,container_id,container_name,status,ports | 容器信息 |
| docker_image | id,image_id,repository,tag,size | 镜像信息 |
| docker_image_log | id,image_id,operation,status,message | 镜像操作日志 |
| container_log_segment | id,container_id,segment_type,content | 日志分析段 |

说明：
1. 布尔值使用 TINYINT/SMALLINT (0/1)。
2. TEXT/长字符串映射为 CLOB。
3. JSON 逻辑字段使用 VARCHAR/CLOB 存储，应用层解析。
4. ID 字段 BIGINT 自增 (IDENTITY)。
5. 统一时间列使用 DATETIME(6) 精度或达梦 TIMESTAMP(6)。

## 迁移与自检
- 启动：若启用 AutoMigrate（在初始化阶段），模型与脚本双保险。
- tools/init_db.sh 支持 DB_MODE 分支执行 MySQL create_tables.sql 或 dameng_migration.sql。
- 达梦模式脚本：tools/run_dameng.ps1 一键设置环境 -> 构建 -> 启动 -> 健康检测。
- 自检：InitSchemaSelfCheckAsync() 异步验证关键表+列，日志提示缺失项。
