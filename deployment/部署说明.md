# Andorralee 蜜罐系统部署说明

## 系统概述

Andorralee 是一个完整的蜜罐管理系统，包含：
- **后端服务**: Go语言编写的API服务器（端口8848）
- **数据库**: MySQL 8.0（端口3306）
- **4个蜜罐容器**:
  - shellguard-1: Cowrie SSH蜜罐（端口2222, 2223）
  - shellguard-2: Heralding多协议蜜罐（端口21, 23, 80, 110, 143, 443, 1080, 3389）
  - shellguard-3: Dionaea恶意软件蜜罐（端口445, 135, 1433, 3306, 5060）
  - shellguard-4: MySQL蜜罐（端口3307）

## 目标环境

- **操作系统**: Ubuntu (x86_64)
- **目标IP**: 192.168.1.21
- **用户**: httc / httc@1234
- **前置要求**: Docker, Docker Compose

## 部署步骤

### 第一步：在本地Mac上打包系统

1. 确保你在项目根目录 `/Users/yifei/mygo！！！！！/andorralee`

2. 确保Docker在运行，且4个蜜罐容器都存在：
   ```bash
   docker ps -a | grep shellguard
   ```

3. 确保MySQL数据库可访问：
   ```bash
   mysql -h 127.0.0.1 -P 3306 -u root -pmac123456 -e "USE andorralee; SHOW TABLES;"
   ```

4. 执行打包脚本：
   ```bash
   cd deployment
   bash package.sh
   ```

   这将：
   - 导出所有Docker镜像（约5-10GB）
   - 导出MySQL数据库数据
   - 打包所有必要文件
   - 生成 `andorralee-deploy-YYYYMMDD-HHMMSS.tar.gz`

5. 打包完成后，在项目根目录会生成部署包文件

### 第二步：传输到目标服务器

使用scp传输打包文件到目标服务器：

```bash
# 将 YYYYMMDD-HHMMSS 替换为实际的时间戳
scp andorralee-deploy-YYYYMMDD-HHMMSS.tar.gz httc@192.168.1.21:~/
```

输入密码：`httc@1234`

### 第三步：在目标服务器上部署

1. SSH登录到目标服务器：
   ```bash
   ssh httc@192.168.1.21
   # 密码: httc@1234
   ```

2. 解压部署包：
   ```bash
   tar -xzf andorralee-deploy-*.tar.gz
   cd andorralee-package/deployment
   ```

3. 确保用户在docker组（如果不在，需要先添加）：
   ```bash
   sudo usermod -aG docker httc
   # 然后重新登录
   ```

4. 执行部署脚本：
   ```bash
   bash deploy.sh
   ```

   部署脚本将自动：
   - 检查Docker环境
   - 导入所有Docker镜像
   - 创建Docker网络和卷
   - 启动MySQL数据库
   - 导入数据库结构和数据
   - 构建并启动后端服务
   - 启动4个蜜罐容器

5. 等待服务启动（约1-2分钟）

### 第四步：验证部署

1. 查看所有容器状态：
   ```bash
   docker ps
   ```

   应该看到6个运行中的容器：
   - andorralee-mysql
   - andorralee-backend
   - shellguard-1
   - shellguard-2
   - shellguard-3
   - shellguard-4

2. 检查后端服务：
   ```bash
   curl http://localhost:8848/api/v1/health
   ```

   应该返回：`{"code":0,"message":"success","data":"healthy"}`

3. 访问前端页面：
   ```
   http://192.168.1.21:8848/index.html
   ```

4. 查看日志：
   ```bash
   cd deployment
   docker-compose -f docker-compose.deploy.yml logs -f andorralee-backend
   ```

## 管理命令

进入deployment目录后：

```bash
cd ~/andorralee-package/deployment
```

### 查看服务状态
```bash
docker-compose -f docker-compose.deploy.yml ps
```

### 查看日志
```bash
# 所有服务日志
docker-compose -f docker-compose.deploy.yml logs -f

# 特定服务日志
docker-compose -f docker-compose.deploy.yml logs -f andorralee-backend
docker-compose -f docker-compose.deploy.yml logs -f mysql
docker-compose -f docker-compose.deploy.yml logs -f shellguard-1
```

### 停止服务
```bash
docker-compose -f docker-compose.deploy.yml stop
```

### 启动服务
```bash
docker-compose -f docker-compose.deploy.yml start
```

### 重启服务
```bash
docker-compose -f docker-compose.deploy.yml restart
```

### 重启单个服务
```bash
docker-compose -f docker-compose.deploy.yml restart andorralee-backend
```

### 完全删除服务（包括数据）
```bash
docker-compose -f docker-compose.deploy.yml down -v
```

## 数据持久化

所有重要数据都通过Docker卷持久化：

- `mysql-data`: MySQL数据库数据
- `andorralee-logs`: 后端日志
- `cowrie-logs`: Cowrie蜜罐日志
- `heralding-logs`: Heralding蜜罐日志
- `dionaea-logs`: Dionaea蜜罐日志
- `mysql-honeypot-logs`: MySQL蜜罐日志

即使删除容器，数据也不会丢失（除非使用 `docker-compose down -v`）

## 故障排查

### 1. 容器启动失败

查看容器日志：
```bash
docker logs andorralee-backend
docker logs andorralee-mysql
```

### 2. 端口冲突

检查端口占用：
```bash
sudo netstat -tlnp | grep -E "8848|3306|2222|3307"
```

如果有冲突，修改 `docker-compose.deploy.yml` 中的端口映射

### 3. 后端无法连接数据库

检查数据库容器健康状态：
```bash
docker inspect andorralee-mysql | grep -A 10 Health
```

手动测试数据库连接：
```bash
docker exec andorralee-backend ping mysql
```

### 4. Docker镜像加载失败

手动加载镜像：
```bash
cd deployment/images
gunzip -c cowrie-v0.1.tar.gz | docker load
gunzip -c heralding-v0.1.tar.gz | docker load
gunzip -c dionaea-v1.tar.gz | docker load
gunzip -c dbdefende-r2-v1.0.tar.gz | docker load
gunzip -c mysql-8.0.tar.gz | docker load
```

### 5. 重新初始化数据库

```bash
# 删除数据库卷
docker volume rm deployment_mysql-data

# 重新启动服务
cd deployment
docker-compose -f docker-compose.deploy.yml up -d mysql

# 等待数据库初始化
sleep 30

# 启动其他服务
docker-compose -f docker-compose.deploy.yml up -d
```

## 网络架构

所有服务都在 `andorralee-network` 桥接网络中：

```
andorralee-network (172.x.x.x/16)
├── andorralee-mysql (数据库)
├── andorralee-backend (后端，可访问Docker socket)
├── shellguard-1 (Cowrie)
├── shellguard-2 (Heralding)
├── shellguard-3 (Dionaea)
└── shellguard-4 (MySQL蜜罐)
```

后端服务通过 Docker socket 管理蜜罐容器。

## 备份与恢复

### 备份

```bash
# 备份数据库
docker exec andorralee-mysql mysqldump -uroot -pmac123456 andorralee > andorralee_backup_$(date +%Y%m%d).sql

# 备份所有卷
docker run --rm -v deployment_mysql-data:/data -v $(pwd):/backup alpine tar czf /backup/mysql-data-backup.tar.gz /data
```

### 恢复

```bash
# 恢复数据库
docker exec -i andorralee-mysql mysql -uroot -pmac123456 andorralee < andorralee_backup_YYYYMMDD.sql
```
